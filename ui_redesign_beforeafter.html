타이포그래피 위계 — 챌린지 피드 카드

아쉬운 UI: 모든 텍스트가 동일한 크기·굵기·색상으로 나열되어 있어, 사용자는 무엇을 먼저 읽어야 할지 판단하는 데 인지 에너지를 소모합니다.
개선 방향: 제목(크고 굵음) → 본문(중간, 회색) → 메타정보(작고 흐림) 3단계 위계로 시선의 흐름을 자연스럽게 유도합니다. 참고 원칙: Wathan & Schoger, "Refactoring UI" — Visual Hierarchy

Empty State 디자인 — AI 다이어리 첫 화면

아쉬운 UI: 아무것도 없을 때 그냥 빈 화면과 회색 텍스트만 표시합니다. 무기력 청년에게 "아무것도 없다"는 느낌은 오히려 시작을 더 어렵게 만들 수 있습니다.
개선 방향: 빈 상태를 '아직 시작 안 한 상태'가 아닌 '오늘 시작할 수 있는 기회'로 재프레이밍합니다. 일러스트·격려 문구·낮은 진입점 버튼으로 심리적 장벽을 낮춥니다. 참고 사례: Duolingo 빈 상태, Finch 첫 화면 — Emotional Design

핵심 디자인 원칙 요약

Case 1
타이포그래피 위계
정보를 Bold → Regular → Light 3단계로 나누면 인지부하가 줄고 브랜드 신뢰도가 올라간다. (Refactoring UI, Wathan & Schoger)
Case 2
감정적 Empty State
빈 화면을 결핍이 아닌 기회로 전환한다. ShallWe의 "무압박 UX" 철학과 직결되는 원칙 — 미완수를 실패로 표현하지 않는다.
공통
ShallWe UX 방향성
두 개선 모두 심리적 장벽을 낮추고, 작은 행동의 시작을 부드럽게 유도한다는 서비스 핵심 가치를 UI 레벨에서 구현한다.
