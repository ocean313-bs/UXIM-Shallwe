1
좋은 UI — 알림 설정 화면

왜 잘 됐나요? 정보를 세 개의 섹션("챌린지 / AI 다이어리 / AI 감정 알림")으로 명확히 그룹화하고, 항목 이름(14px Bold)→설명(12px 회색)의 2단계 타이포그래피 위계를 적용했습니다. 하단 info-box는 핵심 정보를 방해 없이 전달합니다.

2
아쉬운 UI → 개선안 — 마이페이지 챌린지 현황

어떤 부분이 아쉬운가요? 프로필 카드의 챌린지 현황에 "D-67 · 완수 33%"가 표시됩니다. 이는 남은 일수와 낮은 달성률을 동시에 강조해 "아직 많이 남았다"는 인상을 줍니다. ShallWe의 핵심 UX 철학("무압박, 실패를 실패로 표현하지 않음")과 정면으로 충돌합니다.
개선 방향: "D-67" → "벌써 33일!" 로 성취 중심 재프레이밍. 프로그레스 바 레이블도 완료 중심으로 변경.

이번 리디자인의 핵심 원칙

Case 1 · 좋은 UI
정보 그룹화 + 타이포 위계
섹션 레이블로 정보를 그룹화하고, Bold→Regular→Light 위계로 인지부하를 낮췄다. 알림 설정 화면에서 잘 구현됨.
Case 2 · 아쉬운 UI
부정적 프레이밍 문제
"D-67 · 완수 33%"는 남은 것·부족한 것을 강조해 무압박 UX 철학과 충돌. UI 카피와 서비스 철학은 반드시 일치해야 한다.
개선안
성취 중심 재프레이밍
"벌써 33일!"로 같은 정보를 달리 표현. ShallWe AI 알림 로직("이미 한 것에 집중")을 UI 레벨에서 일관되게 구현.
