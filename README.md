기존 서비스는 이 문제를 충분히 해결하지 못합니다.

- 상담 앱은 대면 상담의 진입 장벽과 비용 부담이 큼
- 일반 투두리스트 앱은 무기력한 사용자의 상태를 고려하지 않음
- 챌린지 앱은 실패 기록이 쌓일 때 오히려 자책감을 유발할 수 있음
- 범용 AI 상담은 무조건적인 위로 또는 피상적인 조언에 머물 수 있음

## Solution

Shallwe는 사용자의 무기력 정도를 파악하고, 감정 기록을 통해 자책·반추 사고를 인지하게 하며, 작은 행동 단위의 챌린지를 추천합니다.

서비스는 사용자를 강하게 밀어붙이기보다, 부담 없는 인터랙션과 작은 성취를 통해 회복의 흐름을 만들어가는 데 집중합니다.

## Key Features

### 1. 무기력 검사와 챌린지 추천

사용자는 무기력 검사를 통해 현재 상태를 확인하고, 선호도에 맞는 챌린지를 추천받을 수 있습니다.

- PHQ-9 기반 무기력 정도 확인
- 무기력 정도를 단계별로 구분
- 활동성, 혼자/함께, 성취/루틴, 기간 등 선호도 반영
- 맞춤형 챌린지 추천
- 사용자가 직접 챌린지 생성 가능

> 본 서비스는 의료 진단을 제공하지 않으며, 사용자의 자기 이해와 일상 행동 회복을 돕는 보조 도구입니다.

### 2. 챌린지 인증 및 커뮤니티

사용자는 작은 일상 행동을 사진으로 기록하며 성취감을 쌓을 수 있습니다.

- 산책하기
- 세끼 먹기
- 샤워하기
- 요리하기
- 짧은 정리하기

챌린지는 공개 또는 비공개로 기록할 수 있으며, 공개 시 커뮤니티에 공유됩니다.

커뮤니티는 타인의 성과를 비교하는 공간이 아니라, 비슷한 여정을 걷는 사람들의 노력을 확인하며 고립감을 줄이는 공간으로 설계됩니다.

### 3. AI 다이어리

사용자는 하루의 감정과 경험을 기록하고, AI로부터 감정 및 사고 패턴에 대한 피드백을 받을 수 있습니다.

- 감정 일기 작성
- 오늘의 경험에 대한 유도 질문 제공
- 자책 사고 탐지
- 반추 사고 패턴 인지
- 상태에 맞는 챌린지 추천

AI는 해결책을 강요하기보다 사용자가 자신의 감정과 생각을 객관적으로 바라볼 수 있도록 돕는 보조 도구로 사용됩니다.

## Target Users

- 쉬었음 기간을 경험하고 있는 청년
- 취업 준비 과정에서 번아웃을 겪는 사용자
- 목표는 있지만 시작이 어려운 사용자
- 실패 후 자책과 반추가 반복되는 사용자
- 대면 상담은 부담스럽지만 감정 정리는 필요한 사용자
- 작은 성취를 통해 일상 회복을 시작하고 싶은 사용자

## User Research

Shallwe는 설문조사와 인터뷰를 통해 다음 인사이트를 도출했습니다.

- 쉬었음 청년의 핵심 페인포인트는 정서적 무기력에 가까움
- 무기력의 원인으로 취업·진로 불안, 반복되는 실패, 자책 사고가 자주 나타남
- 작은 성취를 제공하는 마이크로 스텝 챌린지가 유효함
- 실패 표시가 쌓이는 UI는 자책감을 유발할 수 있음
- 사용자는 AI에 양가감정을 가지지만, 감정을 정리하고 인지하는 도구로는 긍정적으로 받아들임
- 타인의 성공보다 타인의 노력을 보는 것이 동기부여에 더 적합함

## UX Principles

- 비강요적 인터랙션
- 자책감을 유발하지 않는 UI
- 작은 행동 중심의 챌린지
- 감정 인지를 돕는 AI 피드백
- 비교보다 공감과 소속감을 제공하는 커뮤니티
- 따뜻하고 단순한 시각 언어

- 간단한 챌린지 추천이 바로 실행을 유도함

- 앱 구조가 복잡하지 않고 깔끔함

- AI 다이어리 유도 질문 구체화 필요
