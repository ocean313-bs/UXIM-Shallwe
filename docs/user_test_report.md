## 시나리오 1 : 회원가입 후 맞춤형 챌린지 선택

> 당신은 광고를 통해 'shallwe'를 알게 되어 앱을 처음 설치했습니다. 무기력감을 극복하고 싶은 마음으로 앱을 열었습니다. 회원가입 후 맞춤형 챌린지를 선택해보세요.

### 관찰 내용 (행동 / 반응)
- 온보딩 4페이지를 ">" 화살표로 넘김. 화살표가 SVG 아이콘이라 클릭 영역이 매우 작음 (16x16px)
- "스킵" 버튼으로 온보딩을 건너뛸 수 있음
- 회원가입 폼 (닉네임/이메일/비밀번호) 입력 후 바로 무기력 측정 9문항 시작
- 9문항 완료 후 "결과 분석 완료!" → "챌린지 시작" → 추천 챌린지 2개 + 직접 만들기 제시
- 챌린지 선택 시 확인 모달 → 추가 완료 메시지 → 홈 이동

### 주요 문제점 (Pain Point)
1. **온보딩 ">" 화살표 클릭 영역이 너무 작음** - 16x16px SVG 아이콘만 클릭 가능. 스와이프 제스처 미지원
2. **결과 분석 화면에 실제 분석 결과(점수/수준)가 표시되지 않음** - "결과 분석 완료!"만 나오고 내 무기력 수준이 어떤지 알 수 없음
3. **온보딩 페이지에 일러스트/이미지 없이 텍스트만 있어 시각적으로 밋밋함**
4. **"스킵" 버튼의 위치(좌하단)가 직관적이지 않음** - 일반적으로 우상단에 위치

### 사용자 발화 (인상 깊은 코멘트)
- "결과가 어떻게 나왔는지 안 보여주나? 왜 바로 챌린지 선택으로 넘어가지?"

### 인사이트 도출
- 무기력 측정 결과 피드백이 없으면 사용자가 "왜 이 챌린지가 추천됐는지" 이해하기 어려움
- 측정 결과 요약(예: "경도 무기력") + 추천 이유를 보여줘야 챌린지 선택에 대한 신뢰도와 동기부여가 높아짐

## 시나리오 2 : AI 다이어리에 감정 기록 및 AI 분석

> 오늘 있었던 일로 인해 자책하는 마음이 듭니다. 잠들기 전, 이 기분을 다이어리에 기록하고 감정을 분석 받고 싶습니다. 자신의 감정을 기록하고 AI분석을 받아보세요.

### 주요 화면

| AI 다이어리 캘린더 | 오늘의 기록 작성 |
|:---:|:---:|
| ![캘린더](screenshots/07_diary_calendar.png) | ![기록](screenshots/08_diary_write.png) |

| AI 감정 분석 결과 |
|:---:|
| ![분석](screenshots/09_ai_analysis.png) |

### 관찰 내용 (행동 / 반응)
- 하단 네비게이션 "AI 다이어리" 탭 클릭 → 캘린더 뷰 + "오늘의 일기 쓰기" 버튼
- 감정 슬라이더(부정적-보통-긍정적) 조절 + 텍스트 입력 후 "AI 감정 분석 보기" 클릭
- AI 분석 결과: "AI의 따뜻한 응원" 형태로 '과한 자책', '반추사고' 패턴 분석
- 오늘의 챌린지 추천: "좋아하는 영상 보며 차 한잔 마시기"
- "도움이 됐어요" / "공감이 안 돼요" 피드백 버튼 제공

### 주요 문제점 (Pain Point)
1. **감정 슬라이더가 3단계(부정적/보통/긍정적)뿐이라 세밀한 감정 표현이 어려움**
2. **"AI 감정 분석 보기" 버튼이 비활성 상태처럼 보임** (회색 톤) - 입력 완료 후 활성화 피드백 부족
3. **분석 결과 화면에서 뒤로가기 시 앱이 초기 온보딩으로 리셋됨** - 상태 관리 버그
4. **캘린더에 과거 날짜에 기록된 감정 점(dot)이 있지만, 클릭해서 과거 기록을 열람하는 흐름이 불명확**

### 사용자 발화 (인상 깊은 코멘트)
- "AI가 반추사고라고 분석해줘서 신기하다. 근데 챌린지 추천은 좀 갑자기 나오는 느낌"

### 인사이트 도출
- AI 분석 → 챌린지 추천의 연결 로직이 사용자에게 자연스럽게 전달되어야 함 ("당신의 감정 패턴에 따르면..." 등 맥락 제공)
- 상태 관리 리셋 버그는 프로토타입 한계이지만, 실제 개발 시 반드시 해결 필요

## 시나리오 3 : 챌린지 인증 및 커뮤니티 공유

> 선택했던 챌린지를 마쳤습니다. 이 작은 성취를 앱에 기록하고 커뮤니티에 공유하고 싶습니다. 챌린지를 인증하고 공유해보세요.

### 주요 화면

| 챌린지 인증 | 홈 (커뮤니티 피드) |
|:---:|:---:|
| ![인증](screenshots/10_challenge_verify.png) | ![홈](screenshots/11_home.png) |

### 관찰 내용 (행동 / 반응)
- "인증하기" 탭 클릭 → 사진 찍기/갤러리 선택 + 진행 중 챌린지 태그 선택 + 글 작성 + 업로드
- 진행 중인 챌린지가 태그(칩) 형태로 표시됨 (산책 10분 하기, 하루에 한 번 하늘 보기)
- 업로드 후 홈 화면의 "모두의 챌린지" 섹션에 커뮤니티 게시글 형태로 표시

### 주요 문제점 (Pain Point)
1. **챌린지 태그 선택 시 시각적 피드백(선택됨 표시)이 불명확** - 어떤 챌린지가 선택됐는지 구분 어려움
2. **업로드 완료 후 성공 토스트/모달 없이 바로 홈으로 이동** - 업로드가 됐는지 확인 불가
3. **사진 없이도 업로드가 가능** - 인증의 의미가 퇴색될 수 있음
4. **"커뮤니티 공유" 옵션이 별도로 없음** - 인증 = 자동 공유인지, 선택적 공유인지 불명확

### 사용자 발화 (인상 깊은 코멘트)
- "내 인증글이 올라간 건 맞는 거지? 완료 메시지가 없어서 좀 불안하다"

### 인사이트 도출
- 인증 완료 시 명확한 성공 피드백(예: "인증 완료! 오늘도 한 걸음 성장했어요") + 커뮤니티 공유 여부 선택지 필요
- 사진 필수/선택을 구분하여 인증의 신뢰성을 높일 수 있음

## 시나리오 4 : 챌린지 기록 확인

> 앱을 사용한 지 2주가 지났습니다. 그동안 내가 얼마나 꾸준히 챌린지를 수행했는지 확인하며 성취감을 느끼고 싶습니다. 챌린지 기록을 확인해보세요.

### 주요 화면

| 마이 페이지 | 100일 챌린지 기록 |
|:---:|:---:|
| ![마이](screenshots/12_mypage.png) | ![기록](screenshots/13_challenge_record.png) |

### 관찰 내용 (행동 / 반응)
- "마이" 탭 → 프로필(테스트님) + 진행 중 챌린지 카드 2개 + 설정 + "내 게시글" 섹션
- 챌린지 카드 클릭 → "100일 챌린지" 상세: 진행률(17/100일), 이번 달 완수 현황 캘린더, 오늘 챌린지
- 캘린더에서 완수일은 진한 색, 미완수일은 연한 색으로 구분

### 주요 문제점 (Pain Point)
1. **전체 기간 통계가 한눈에 보이지 않음** - 연속 완수 일수, 달성률(%) 등 성취감을 줄 수 있는 수치가 부족
2. **캘린더가 현재 달만 표시** - 과거 달의 기록을 확인하려면 어떻게 하는지 불명확
3. **챌린지 카드의 프로그레스 바가 너무 작아서 진행률을 직관적으로 파악하기 어려움**
4. **"내 게시글"에 이미지 썸네일만 있고 텍스트/날짜 정보가 없음**

### 사용자 발화 (인상 깊은 코멘트)
- "17일 했다는 건 알겠는데, 연속으로 한 건지 중간에 빠진 건지 모르겠다"

### 인사이트 도출
- 성취감 극대화를 위해 "연속 N일 달성!", "이번 주 달성률 80%" 등 게이미피케이션 요소 추가 필요
- 기록 확인 화면이 성취를 축하하는 톤으로 디자인되면 사용자의 지속 사용 동기 강화

## 종합 인사이트

### 우선순위별 개선 항목

| 우선순위 | 개선 항목 | 영향도 | 관련 시나리오 |
|:---:|---------|:---:|:---:|
| 1 | 무기력 측정 결과 피드백 화면 추가 | 높음 | S1 |
| 2 | 인증 완료 성공 피드백 추가 | 높음 | S3 |
| 3 | 성취 통계(연속일수, 달성률) 표시 | 높음 | S4 |
| 4 | 온보딩 스와이프 지원 + 클릭영역 확대 | 중간 | S1 |
| 5 | AI 분석 → 챌린지 추천 연결 맥락 강화 | 중간 | S2 |
| 6 | 감정 슬라이더 세분화 | 낮음 | S2 |

### 전체 플로우 요약

```
[온보딩 4페이지] → [회원가입] → [무기력 측정 9문항] → [결과 분석] → [챌린지 선택]
                                                                          ↓
                     [마이페이지] ← [홈 (커뮤니티)] ← [챌린지 인증] ← [홈]
                          ↓               ↑
                   [챌린지 기록]    [AI 다이어리] → [AI 감정 분석]
```

### 긍정적 발견
- 온보딩 → 측정 → 챌린지 선택까지의 전체 플로우가 논리적으로 잘 연결됨
- AI 감정 분석의 '과한 자책', '반추사고' 등 심리학 용어 활용이 전문적인 인상을 줌
- 커뮤니티 피드에서 다른 사용자의 챌린지 인증글을 볼 수 있어 동기부여 요소가 됨
- 100일 챌린지 캘린더 뷰가 시각적으로 완수 현황을 파악하기 쉬움
